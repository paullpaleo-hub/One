Privacy Policy

Last updated: November 2026

TikTok Master Machine ("the app") is a private macOS desktop tool used only by its owner. There is no server operated by the app. All processing happens on the owner's Mac.

Data from TikTok

When the user connects their TikTok account, the app receives an access token, a refresh token, the open ID and basic profile information (display name, avatar, follower and video counts). It may also read the list of the user's own videos and their view, like, comment and share counts to improve posting recommendations.

Where data is stored

Tokens are stored only in the macOS Keychain on the user's Mac. Profile information, video statistics and app settings are stored in a local database on the user's own drive. No data is sent to the app owner or to any third party.

Videos

Videos are analyzed locally on the Mac. A video is uploaded to TikTok only after the user approves that specific post. Videos are not sent to any other service.

Deletion

The user can disconnect TikTok in the app at any time. This revokes the token at TikTok and deletes it from the Keychain. The user can also delete all local app data from the app settings.
